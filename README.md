
# Restaurant Ordering System

A full-stack web application that allows customers to browse food items, view categories, register, log in, and place food orders online.

## Technologies Used

### Backend
- C#
- ASP.NET Core Web API (.NET 8)
- Entity Framework Core
- JWT Authentication

### Frontend
- Angular
- TypeScript
- HTML
- CSS

### Database
- Microsoft SQL Server

## Main Features

- Customer registration and login
- JWT-based authentication
- Browse food categories
- View available food items
- Place food orders
- Manage orders

## Project Structure

- Backend – ASP.NET Core Web API
- Frontend – Angular application
